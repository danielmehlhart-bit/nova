# NOVA founding-community playtest — 6 September 2026

Real browser clickthrough in the Codex in-app browser, using a separate local preview. The new city began empty and reached chapter 6 with 41 residents. Viewports: 1280×720, 390×844, 320×568 and 844×390. No simulation state was injected into the browser. This is an agent playtest, not a human retention study or physical handset certification.

## Observed flow

Intro → choose a campsite as one test example → place → actual arrivals → shared pool with disco after 18 → autonomous circles → citizen vote → new co-living courtyard for 20 → residents voluntarily change homes → free resident conversation → procedural workshop proposal → explicit build → own named housing for nine → city report. The campsite was a test choice, not a required opening. The alternative free-housing UI and typed description both worked.

## Automated verification

37 engine/contract tests pass, including all original legacy regressions and new founding, programme boundary, autonomous circle, voluntary relocation, housing-capacity, council cooldown, vote/delegate, save-validation and grounded-context cases. TypeScript and authored-code lint pass. Both the private-hosting project and standalone open-source checkout build successfully. Release inspection checks the actual server-secret value against tracked/new source and built artifacts without printing it.

## What remains unproven

Microphone capture and speech playback on physical iPhone/Android hardware; long-duration GPU/memory/thermal behavior on low-end phones; multi-hour fun and pacing with human players; social model realism. No claim of Sims-2 asset/animation parity. There are no detailed interiors, collision pathfinding, crime/justice simulation, complete family life cycles, public constitution voting or account synchronization yet. Local rule-driven autonomy is different from independently running background language models.

## Next playtest questions

Can a new player explain the role after the intro? Do they invent a home without assuming the examples are mandatory? Can they identify one unhappy minority hidden by a good average? Do they care about a person enough to change a place? Do they want to watch what happens tomorrow? Tune that experience before adding large institutions or content volume.
